# Class equipment proficiencies

Modern WoW-style proficiencies apply to the weapon families available in this
game. Armor users may wear lighter categories too; there are no level-40 training
gates or armor-specialization set bonuses in this level-20 game.

| Class | Maximum armor | Weapons |
| --- | --- | --- |
| Warrior | Plate | All existing weapon families except wands; shields |
| Paladin | Plate | Swords/greatswords, axes, maces, polearms; shields |
| Death Knight | Plate | Swords/greatswords, axes, maces, polearms |
| Hunter | Mail | Swords/greatswords, axes, daggers, bows, crossbows, guns, polearms, staves, fists |
| Shaman | Mail | Axes, maces, daggers, fists, staves; shields |
| Evoker | Mail | Swords/greatswords, axes, maces, daggers, fists, staves |
| Rogue | Leather | Swords, axes, maces, daggers, fists, bows, crossbows, guns |
| Monk | Leather | Swords, axes, maces, fists, staves, polearms |
| Druid | Leather | Maces, daggers, fists, staves, polearms |
| Demon Hunter | Leather | Swords, axes, fists, daggers, warglaives |
| Priest | Cloth | Daggers, maces, staves, wands |
| Mage / Warlock | Cloth | Swords, daggers, staves, wands |

Greatswords, bows, crossbows, guns, polearms and staves occupy both hands.
Equipping them returns an offhand to storage. Equipping an offhand while using
a two-handed weapon is blocked. The existing one-weapon-slot game does not add
dual-wield damage or specialization-specific weapon bonuses.

Rings, capes and utility supplies remain class-neutral. Shields require their
class proficiency. Incompatible choices are filtered and direct equipment calls
are validated before payment. Respecialization and old saves return incompatible
gear to guild storage with all bonuses, durability and identity preserved.
Away heroes retain carried gear until their sealed expedition resolves.

Legacy items use their saved family or matching crafted recipe; otherwise their
name identifies the type, with a stat-based fallback for untyped weapons/armor.
Future crafted items already save their explicit family.

Staff cards show the assigned skill's level and practice bar outside the skills
foldout. All saved skills have bars inside it. Bars use the existing cumulative
thresholds, show practice remaining for the next level, and show mastery at 10.
No experience, wage, assignment or practice-award rules change.
