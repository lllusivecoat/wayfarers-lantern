# Gathering checks and Charisma contracts

Each gathering mission accepts either of two stats. Every hero makes one roll using whichever listed stat gives higher readiness; ties use the first listed stat. Different party members may use different stats. There are no phase averages or second checks. The usual party outcome, injuries, fees, tool wear, utilities and rewards apply once.

| Profession | Either | Or |
| --- | --- | --- |
| Mining | STR | CON |
| Fishing | DEX | WIS |
| Herbalism | WIS | INT |
| Skinning | DEX | STR |
| Woodcutting | STR | CON |
| Tailoring | DEX | INT |
| Jewelcrafting | INT | DEX |
| Hunting | DEX | WIS |

Readiness selection includes equipped gear and prepared utility bonuses. Stat-conditional perks use the selected stat, with existing caps and once-only rules. Quest badges say STR or CON (or the relevant pair), and member previews show both readiness values and the automatically selected stat.

Reports record one set of rolls and the stat used by each hero. Already sealed two-phase reports retain their original rolls and outcomes, and still render both old phases; no rewards are recalculated. Older single-stat reports remain unchanged.

Charisma contract stat weights:

| Type | Stat weights |
| --- | --- |
| Diplomatic courier | CHA 100% |
| Escort / delivery | CHA 40%, CON 30%, WIS 30% |
| Investigation / observation | INT 50%, WIS 30%, CHA 20% |
| Exploration / rescue contracts | WIS 40%, INT 30%, CHA 30% |

Permanent exploration missions retain their existing WIS check. Only these suitable social contract types change; combat encounters and convoys retain their existing rules. When no CHA contract is currently available, one eligible unaccepted social offer may switch to CHA, once per game day. This does not generate duplicate offers, bypass location unlocks or modify already dispatched reports. If the board has no eligible social offer, it does not manufacture one.

Browser coverage: all eight pairs, one actual d20 roll, higher-readiness and tie selection, secondary-stat modifiers, normal party outcomes, context preservation, single fee/charge/XP award, saved full reports, CHA stat weights and current offer adaptation, sealed report preservation, gathering expertise and staged world regressions, save/reload and offline updates.
