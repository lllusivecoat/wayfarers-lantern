# Aligned portraits 051–150

100 normalized 128×128 WebP icons made from existing artwork. No image-generation calls. Originals remain in their batch folders. Circular masks and centred crops replace the original padding and painted rim; the game draws one shared border. Retained source atlases supply the full circle where available. Legacy cropped files use a centred cover crop, avoiding blank strips without generating missing artwork. Rebuild with `python3 beta/art/portraits/chibi/tools/align.py 51 150` then `python3 beta/art/portraits/chibi/tools/catalog.py`.
